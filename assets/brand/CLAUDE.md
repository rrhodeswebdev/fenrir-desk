# assets/brand/

Fenrir Desk's visual identity: logo lockups, mark, wordmark, app icons, palette and type.

- `README.md` is the brand guide: which file to use where, palette tokens, typography.
- `logo/`, `icon/`: SVG sources (text outlined). `*/png/`: rendered PNGs at fixed sizes.
- Not here: UI component styles. The web app (`web/`) copies palette values from `README.md`.
- Use the simplified icon at 128px and below.
