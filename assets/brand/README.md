# Fenrir Desk brand assets

All SVGs have text converted to outlines, so they render the same everywhere without needing the fonts installed.

## Files

| Folder | What it holds |
| --- | --- |
| `logo/` | Full lockup (mark + wordmark + tagline) in dark and light versions, each with a solid or transparent background; mark only; wordmark only |
| `logo/png/` | PNG renders of the lockups (1200px wide) and the mark (512px) |
| `icon/` | App icon SVGs: `app-icon` (detailed), `app-icon-simple` (for small sizes), `app-icon-accent`, `app-icon-mono` |
| `icon/png/` | App icon at 1024, 512 and 256px (detailed) and at 128, 64, 32 and 16px (simplified) |

Use the simplified icon at 128px and below, where the detailed facets turn to mush.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Night | `#0E1116` | Dark background |
| Frost | `#EEF1F4` | Light background |
| Steel | `#C9D3DD` | Mark base on dark |
| Ice | `#E8EEF4` | Wordmark on dark |
| Slate | `#8FA0B2` | Tagline / secondary on dark |
| Ink | `#141A22` | Mark and wordmark on light |
| Ember | `#E0A33A` | Accent: eyes, "DESK" on dark |
| Ember Deep | `#8A5A0E` | Accent text on light (for contrast) |

## Type

- **Chakra Petch** 700 for "FENRIR" (tracking 0.18em) and 600 for "DESK" (tracking 0.62em)
- **IBM Plex Mono** 400 for the tagline (tracking 0.3em)

Both are free on Google Fonts (OFL).
