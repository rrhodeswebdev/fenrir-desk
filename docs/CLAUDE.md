# docs/

Design and planning documents. Nothing here runs.

`docs/superpowers/` is gitignored: the spec and plans exist only on the machine that wrote them, so a fresh clone will not have them.

- The v1 source of truth is the root `SPEC.md`, not anything in this directory.
- `superpowers/specs/`: superseded design specs, kept as history.
- `superpowers/plans/`: implementation plans. Start at `superpowers/plans/README.md` (plan index, repo layout, cross-plan contracts).
- When code and a spec disagree, the spec is wrong or the code has a bug: ask, don't silently pick one.
