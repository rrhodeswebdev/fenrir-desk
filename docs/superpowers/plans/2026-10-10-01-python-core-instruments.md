# Python Core and Instruments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `uv` Python project with a working `fenrir` CLI, `.env` settings, the pure shared domain types (`Bar`, actions, contract specs), the rollover calendar and trading-day helpers that every later plan builds on.

**Architecture:** src-layout package `fenrir`. `fenrir.core` is pure: frozen slotted dataclasses and functions with no I/O. The only I/O in this plan is `load_instruments` (reads `instruments.yaml`) and `load_settings` (reads `.env` and `os.environ`), each a thin wrapper over a pure parser. The rollover calendar is generated by a pure function from the CME roll rule instead of being typed out by hand.

**Tech Stack:** Python 3.12, `uv`, `hatchling`, `typer`, `pyyaml`, `pytest`, `ruff`.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§2 Storage, §3 Contracts and rollover)
**Index:** `docs/superpowers/plans/README.md` (cross-plan contracts: "Plan 01 — `fenrir.core` and settings")

## Global Constraints

- Python `>=3.12`, managed with `uv`; package `fenrir` in `src/fenrir/`; console script `fenrir = "fenrir.cli.main:app"`.
- Functional core, imperative shell: core types are `@dataclass(frozen=True, slots=True)`; collections are tuples; no I/O, clock or randomness in `fenrir.core`.
- Contract specs exactly: ES series ES $50/pt tick 0.25; MES series ES $5/pt tick 0.25; NQ series NQ $20/pt tick 0.25; MNQ series NQ $2/pt tick 0.25.
- MES and MNQ use the ES and NQ prices; only contract specs differ.
- Signals and order levels use **unadjusted front-month** prices; backtests and live trading use the same rollover calendar.
- `.env` is gitignored; `.env.example` is committed with every setting.
- Every directory with its own responsibility gets a `CLAUDE.md` (index template) and a row in root `CLAUDE.md` → "## 6. Directory Map", in the same commit as its first code.
- Commits: Conventional Commits, scope = area (`core`, `cli`), ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **DST weekends**: a bar at 18:30 local on the Sunday DST starts or ends must map to Monday's trading day, not drift by an hour. Pinned in Task 3 (`test_trading_day_across_dst_start`, `test_trading_day_across_dst_end`).
2. **Evening session vs flat-by**: `at_or_after(ts, "16:45")` must be False for 19:00 the evening before (it is the start of the next trading day), or every evening bar would look past flat-by. Pinned in Task 3 (`test_at_or_after_evening_belongs_to_next_session`).
3. **Roll day itself**: the front month on the roll Thursday is the new contract, on the Wednesday it is the old one. Pinned in Task 4 (`test_front_month_switches_on_roll_day`).
4. **Dates before the calendar**: asking for a front month before the first generated roll must raise a clear `ValueError`, not return a wrong contract. Pinned in Task 4 (`test_front_month_before_calendar_raises`).
5. **Hand-edited `.env`**: comments, blank lines, quoted values, `export KEY=` lines and a non-number in `FENRIR_HOLDOUT_MONTHS` must parse or fail with the key name. Pinned in Task 2 (`test_parse_env_text_handles_comments_and_quotes`, `test_parse_settings_bad_int_names_key`).

`src/fenrir/settings.py`:

```python
import os
from collections.abc import Callable, Mapping
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Literal


@dataclass(frozen=True, slots=True)
class Settings:
    lse_api_key: str = ""
    nt_url: str = "http://host.docker.internal:8123"
    nt_token: str = ""
    holdout_months: int = 12
    safety_margin_pct: float = 80.0
    stale_seconds: int = 90
    heartbeat_policy: Literal["keep", "flatten"] = "keep"
    data_dir: Path = Path("data")
    rules_dir: Path = Path("rules")
    strategies_dir: Path = Path("strategies")


def _policy(value: str) -> str:
    if value not in ("keep", "flatten"):
        raise ValueError(f"must be 'keep' or 'flatten', got {value!r}")
    return value


# field name -> (env key, converter)
_FIELDS: dict[str, tuple[str, Callable[[str], Any]]] = {
    "lse_api_key": ("FENRIR_LSE_API_KEY", str),
    "nt_url": ("FENRIR_NT_URL", str),
    "nt_token": ("FENRIR_NT_TOKEN", str),
    "holdout_months": ("FENRIR_HOLDOUT_MONTHS", int),
    "safety_margin_pct": ("FENRIR_SAFETY_MARGIN_PCT", float),
    "stale_seconds": ("FENRIR_STALE_SECONDS", int),
    "heartbeat_policy": ("FENRIR_HEARTBEAT_POLICY", _policy),
    "data_dir": ("FENRIR_DATA_DIR", Path),
    "rules_dir": ("FENRIR_RULES_DIR", Path),
    "strategies_dir": ("FENRIR_STRATEGIES_DIR", Path),
}


def _convert(key: str, convert: Callable[[str], Any], raw: str) -> Any:
    try:
        return convert(raw)
    except ValueError as e:
        raise ValueError(f"{key}: {e}") from None


def parse_settings(env: Mapping[str, str]) -> Settings:
    return Settings(
        **{
            name: _convert(key, convert, env[key])
            for name, (key, convert) in _FIELDS.items()
            if env.get(key, "") != ""
        }
    )


def parse_env_text(text: str) -> dict[str, str]:
    pairs = (line.strip().split("=", 1) for line in text.splitlines())
    return {
        k.strip().removeprefix("export ").strip(): v.strip().strip('"').strip("'")
        for k, v in (p for p in pairs if len(p) == 2 and not p[0].startswith("#"))
    }


def load_settings(env_file: Path = Path(".env")) -> Settings:
    from_file = parse_env_text(env_file.read_text()) if env_file.exists() else {}
    return parse_settings({**from_file, **os.environ})
```

`src/fenrir/core/sessions.py`:

```python
from datetime import date, datetime, timedelta
from zoneinfo import ZoneInfo

NY = ZoneInfo("America/New_York")
_OPEN = 18 * 60  # CME Globex session opens 18:00 local; trading day D runs 18:00 on D-1 to 17:00 on D


def _require_aware(ts: datetime) -> None:
    if ts.tzinfo is None:
        raise ValueError(f"naive datetime: {ts!r}")


def trading_day(ts: datetime) -> date:
    _require_aware(ts)
    return (ts.astimezone(NY) + timedelta(hours=6)).date()


def _since_open(hour: int, minute: int) -> int:
    return (hour * 60 + minute - _OPEN) % (24 * 60)


def at_or_after(ts: datetime, hhmm: str, tz: str = "America/New_York") -> bool:
    _require_aware(ts)
    local = ts.astimezone(ZoneInfo(tz))
    hour, minute = (int(p) for p in hhmm.split(":"))
    return _since_open(local.hour, local.minute) >= _since_open(hour, minute)
```

### Task 4: Instruments and rollover calendar

**Files:**
- Create: `src/fenrir/core/instruments.py`
- Create: `instruments.yaml`
- Test: `tests/core/test_instruments.py`

**Interfaces:**
- Consumes: nothing.
- Produces (exact, from index): `ContractSpec(symbol, series, point_value, tick, minis)`, `Roll(series, start, contract)`, `Instruments(specs, rolls)`, `load_instruments(path: Path = Path("instruments.yaml")) -> Instruments`, `spec(instruments, symbol) -> ContractSpec` (`ValueError` on unknown), `front_month(instruments, series, day) -> str` (`ValueError` before first roll).
- Also produces: `parse_instruments(doc: Mapping[str, Any]) -> Instruments` (pure), `quarterly_rolls(series: str, first_year: int, last_year: int) -> tuple[Roll, ...]` (pure).

**Roll rule.** CME equity index futures (ES, NQ) trade quarterly: March `H`, June `M`, September `U`, December `Z`, expiring on the third Friday of the month. Volume moves to the next contract on the CME roll date, **8 calendar days before expiry** (always a Thursday). From that trading day on, the next quarter's contract is front month. Codes are `<series><month letter><two-digit year>`, e.g. `NQZ26`. Two digits keep codes unique when history spans more than ten years (`NQZ16` vs `NQZ26`); the LSE symbol format is mapped in `fenrir.data.lse` (plan 03).

`src/fenrir/core/instruments.py`:

```python
from bisect import bisect_right
from collections.abc import Mapping
from dataclasses import dataclass
from datetime import date, timedelta
from pathlib import Path
from typing import Any

import yaml

_LETTERS = {3: "H", 6: "M", 9: "U", 12: "Z"}


@dataclass(frozen=True, slots=True)
class ContractSpec:
    symbol: str  # "ES" | "MES" | "NQ" | "MNQ"
    series: str  # "ES" | "NQ" (price series)
    point_value: float  # $ per point
    tick: float
    minis: float  # mini-equivalents per contract: 1.0 for ES/NQ, 0.1 for MES/MNQ


@dataclass(frozen=True, slots=True)
class Roll:
    series: str
    start: date  # first trading day this contract is front month
    contract: str  # "NQZ26"


@dataclass(frozen=True, slots=True)
class Instruments:
    specs: tuple[ContractSpec, ...]
    rolls: tuple[Roll, ...]  # sorted by (series, start)


def _third_friday(year: int, month: int) -> date:
    first = date(year, month, 1)
    return first + timedelta(days=(4 - first.weekday()) % 7 + 14)


def quarterly_rolls(series: str, first_year: int, last_year: int) -> tuple[Roll, ...]:
    """CME roll: front month moves to the next quarter 8 days before expiry (3rd Friday)."""

    def code(year: int, month: int) -> str:
        return f"{series}{_LETTERS[month]}{year % 100:02d}"

    def next_quarter(year: int, month: int) -> tuple[int, int]:
        return (year + 1, 3) if month == 12 else (year, month + 3)

    return (Roll(series, date(first_year, 1, 1), code(first_year, 3)),) + tuple(
        Roll(series, _third_friday(y, m) - timedelta(days=8), code(*next_quarter(y, m)))
        for y in range(first_year, last_year + 1)
        for m in (3, 6, 9, 12)
    )


def parse_instruments(doc: Mapping[str, Any]) -> Instruments:
    specs = tuple(
        ContractSpec(
            str(c["symbol"]),
            str(c["series"]),
            float(c["point_value"]),
            float(c["tick"]),
            float(c["minis"]),
        )
        for c in doc["contracts"]
    )
    r = doc["rollover"]
    rolls = tuple(
        sorted(
            (roll for s in r["series"] for roll in quarterly_rolls(s, r["first_year"], r["last_year"])),
            key=lambda roll: (roll.series, roll.start),
        )
    )
    return Instruments(specs, rolls)


def load_instruments(path: Path = Path("instruments.yaml")) -> Instruments:
    return parse_instruments(yaml.safe_load(path.read_text()))


def spec(instruments: Instruments, symbol: str) -> ContractSpec:
    for s in instruments.specs:
        if s.symbol == symbol:
            return s
    raise ValueError(f"unknown contract symbol {symbol!r}")


def front_month(instruments: Instruments, series: str, day: date) -> str:
    rolls = [r for r in instruments.rolls if r.series == series]
    i = bisect_right([r.start for r in rolls], day)
    if i == 0:
        first = rolls[0].start if rolls else "none"
        raise ValueError(f"no {series} contract for {day}; calendar starts {first}")
    return rolls[i - 1].contract
```

# Contract specs and rollover calendar. Backtests and live trading both read this file.
# MES and MNQ use the ES and NQ price series; only the contract specs differ.
contracts:
  - { symbol: ES,  series: ES, point_value: 50, tick: 0.25, minis: 1 }
  - { symbol: MES, series: ES, point_value: 5,  tick: 0.25, minis: 0.1 }
  - { symbol: NQ,  series: NQ, point_value: 20, tick: 0.25, minis: 1 }
  - { symbol: MNQ, series: NQ, point_value: 2,  tick: 0.25, minis: 0.1 }

# Quarterly contracts (H M U Z). The front month moves to the next quarter on the
# CME roll date: 8 days before expiry (the third Friday), always a Thursday.
# Raise last_year before it runs out; first_year must not be after the oldest history pulled.
rollover:
  series: [ES, NQ]
  first_year: 2008
  last_year: 2030
