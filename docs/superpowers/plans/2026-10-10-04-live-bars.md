# Live Bars Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the LSE live trade stream into closed 1-minute `Bar`s for the current front-month ES and NQ contracts, matching the historical bars the backtester uses.

**Architecture:** A pure fold, `feed(state, tick) -> (state, closed_bars)`, builds bars from ticks; `close_due(state, now)` closes bars whose minute has ended when the market goes quiet. A small async shell, `_bars_from(ticks, now)`, merges the tick stream with a 1-second timer and yields closed bars; `stream_bars` plugs in the LSE tick stream from `fenrir.data.lse`, the only LSE-aware module. Late ticks for a minute already emitted are dropped, so a bar never changes after the live runner has seen it.

**Tech Stack:** Python 3.12, `asyncio`, `lse-data`.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§3 Live bars, §8 Loop and Failure handling)
**Index:** `docs/superpowers/plans/README.md` ("Plan 04 — `fenrir.data.live`")

> **PROVISIONAL (gate):** `stream_ticks` in `src/fenrir/data/lse.py` is written against the expected `lse-data` streaming API. Task 1 reconciles it with `docs/data-gate.md`.

## Global Constraints

- Requires plan 02's Decision to be GO for items 3–4 (real-time stream; live bars match historical bars). If live is BLOCKED, do not execute this plan.
- Requires plan 03 (`fenrir.data.lse` exists; LSE code lives only there).
- Bars are closed 1-minute bars for the current front-month contract; `Bar.ts` is the bar OPEN time in UTC, the same convention as `load_bars`, so a strategy sees identical bars live and in backtests.
- A bar is emitted once and never changes afterwards.
- No bar is emitted for a minute with no trades (the live runner's stale-data check, plan 21, handles silence).
- Functional core, imperative shell: `feed` and `close_due` are pure; only `_bars_from`, `stream_bars` and `stream_ticks` do I/O.

## Review Focus

1. **Tick exactly on the minute** (`14:31:00.000`) belongs to the 14:31 bar and closes the 14:30 bar. Pinned in Task 2 (`test_tick_on_minute_boundary_starts_new_bar`).
2. **Late or out-of-order ticks** after a bar was emitted must be dropped, never alter or re-emit it; a tick older than the open bar must not overwrite its close. Pinned in Task 2 (`test_late_tick_never_changes_emitted_bar`, `test_tick_older_than_open_bar_is_dropped`).
3. **Quiet market**: when trades stop, the last bar must still close on time from the timer, not wait for the next trade. Pinned in Task 3 (`test_bars_from_closes_bar_when_ticks_stop`).
4. **ES and NQ interleaved, or two contracts across a roll**: each contract builds its own bars. Pinned in Task 2 (`test_contracts_build_separately`).
5. **Disconnect mid-minute**: when the stream ends, a partial bar must not be emitted as if complete. Pinned in Task 3 (`test_bars_from_does_not_emit_partial_bar_on_stream_end`).

`src/fenrir/data/live.py`:

```python
from dataclasses import dataclass, replace
from datetime import UTC, datetime, timedelta

from fenrir.core.bars import Bar

_MINUTE = timedelta(minutes=1)


@dataclass(frozen=True, slots=True)
class Tick:
    ts: datetime
    price: float
    size: int
    contract: str


@dataclass(frozen=True, slots=True)
class _Slot:
    contract: str
    bar: Bar | None  # bar being built
    closed: datetime | None  # open time of the last bar emitted


@dataclass(frozen=True, slots=True)
class BuilderState:
    slots: tuple[_Slot, ...] = ()  # one per contract


def empty_builder() -> BuilderState:
    return BuilderState()


def _slot(state: BuilderState, contract: str) -> _Slot:
    return next((s for s in state.slots if s.contract == contract), _Slot(contract, None, None))


def _put(state: BuilderState, slot: _Slot) -> BuilderState:
    return BuilderState(tuple(s for s in state.slots if s.contract != slot.contract) + (slot,))


def feed(state: BuilderState, tick: Tick) -> tuple[BuilderState, tuple[Bar, ...]]:
    if tick.ts.tzinfo is None:
        raise ValueError(f"naive tick time: {tick.ts!r}")
    slot = _slot(state, tick.contract)
    minute = tick.ts.astimezone(UTC).replace(second=0, microsecond=0)
    if (slot.closed is not None and minute <= slot.closed) or (slot.bar is not None and minute < slot.bar.ts):
        return state, ()  # late tick: an emitted bar never changes
    done: tuple[Bar, ...] = ()
    bar, closed = slot.bar, slot.closed
    if bar is not None and minute > bar.ts:
        done, closed, bar = (bar,), bar.ts, None
    p = tick.price
    bar = (
        Bar(minute, p, p, p, p, tick.size, tick.contract)
        if bar is None
        else replace(bar, high=max(bar.high, p), low=min(bar.low, p), close=p, volume=bar.volume + tick.size)
    )
    return _put(state, _Slot(tick.contract, bar, closed)), done


def close_due(state: BuilderState, now: datetime) -> tuple[BuilderState, tuple[Bar, ...]]:
    def due(s: _Slot) -> bool:
        return s.bar is not None and s.bar.ts + _MINUTE <= now

    bars = tuple(sorted((s.bar for s in state.slots if due(s)), key=lambda b: (b.ts, b.contract)))
    slots = tuple(_Slot(s.contract, None, s.bar.ts) if due(s) else s for s in state.slots)
    return BuilderState(slots), bars
```

from datetime import UTC, datetime

from fenrir.core.bars import Bar
from fenrir.data.live import Tick, _bars_from


def utc(h: int, m: int, s: int = 0) -> datetime:
    return datetime(2026, 10, 8, h, m, s, tzinfo=UTC)


def collect(source, clock, poll: float = 0.01) -> list[Bar]:
    async def go():
        return [b async for b in _bars_from(source, lambda: clock[0], poll=poll)]

    return asyncio.run(go())


def test_bars_from_emits_bar_once_minute_ends():
    clock = [utc(14, 30, 1)]

    async def source():
        for t in (Tick(utc(14, 30, 1), 100.0, 1, "NQZ26"), Tick(utc(14, 30, 40), 101.0, 2, "NQZ26")):
            clock[0] = t.ts
            yield t
        clock[0] = utc(14, 31)

    assert collect(source(), clock) == [Bar(utc(14, 30), 100.0, 101.0, 100.0, 101.0, 3, "NQZ26")]


def test_bars_from_does_not_emit_partial_bar_on_stream_end():
    clock = [utc(14, 30, 5)]

    async def source():
        yield Tick(utc(14, 30, 5), 100.0, 1, "NQZ26")
        clock[0] = utc(14, 30, 30)  # stream drops mid-minute

    assert collect(source(), clock) == []


def test_bars_from_closes_bar_when_ticks_stop():
    clock = [utc(14, 30, 5)]

    async def source():
        yield Tick(utc(14, 30, 5), 100.0, 1, "NQZ26")
        clock[0] = utc(14, 31, 1)
        await asyncio.sleep(3600)  # market goes quiet
        yield Tick(utc(15, 30), 1.0, 1, "NQZ26")

    async def go():
        gen = _bars_from(source(), lambda: clock[0], poll=0.01)
        bar = await asyncio.wait_for(anext(gen), timeout=2)
        await gen.aclose()
        return bar

    assert asyncio.run(go()) == Bar(utc(14, 30), 100.0, 100.0, 100.0, 100.0, 1, "NQZ26")

```python
async def _next(source: AsyncIterator[Tick]) -> Tick | None:
    try:
        return await anext(source)
    except StopAsyncIteration:
        return None


async def _bars_from(
    ticks: AsyncIterator[Tick], now: Callable[[], datetime], poll: float = 1.0
) -> AsyncIterator[Bar]:
    state = empty_builder()
    pending = asyncio.ensure_future(_next(ticks))
    try:
        while True:
            done, _ = await asyncio.wait({pending}, timeout=poll)
            bars: tuple[Bar, ...] = ()
            if done:
                tick = pending.result()
                if tick is None:  # stream ended: emit only bars whose minute is over, never a partial one
                    for b in close_due(state, now())[1]:
                        yield b
                    return
                state, bars = feed(state, tick)
                pending = asyncio.ensure_future(_next(ticks))
            state, due = close_due(state, now())
            for b in bars + due:
                yield b
    finally:
        pending.cancel()


async def stream_bars(settings: Settings, contracts: Sequence[str]) -> AsyncIterator[Bar]:
    from fenrir.data.lse import stream_ticks  # lse imports Tick from here

    async for bar in _bars_from(stream_ticks(settings, contracts), lambda: datetime.now(UTC)):
        yield bar
```

```python
log = logging.getLogger(__name__)


async def stream_ticks(settings: Settings, contracts: Sequence[str]) -> AsyncIterator[Tick]:
    """Live trades for our contract codes. Reconnects forever with backoff up to 30 s."""
    from lse_data import AsyncClient  # PROVISIONAL (gate)

    ours = {lse_symbol(c): c for c in contracts}
    delay = 1.0
    while True:
        try:
            async with AsyncClient(api_key=settings.lse_api_key) as client:  # PROVISIONAL (gate)
                async for t in client.stream_trades(symbols=list(ours)):  # PROVISIONAL (gate)
                    delay = 1.0
                    yield Tick(t.timestamp.astimezone(UTC), float(t.price), int(t.size), ours[t.symbol])
        except OSError as e:  # PROVISIONAL (gate): the client's disconnect error
            log.warning("LSE stream dropped (%s); reconnecting in %.0f s", e, delay)
        await asyncio.sleep(delay)
        delay = min(delay * 2, 30.0)
```
