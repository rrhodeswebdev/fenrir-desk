# Grid and Cache Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run many backtests at once — strategy globs × account globs × contracts — and never recompute a report whose strategy file, rules file, data and settings have not changed.

**Architecture:** `grid.py` expands globs into `GridItem`s (shell: it globs files and reads each strategy's `MARKET`; the contract filtering is a pure helper). `cache.py` keys a report by the plan 09 `report_key` (hashes of strategy bytes, rules bytes, data version, contract, hold-out settings), stores it as `data/results/<key>.json` with an atomic write, and answers "newest report for this strategy hash and account" for arming (plan 23). The CLI from plan 09 switches to grid + cache.

**Tech Stack:** Python 3.12 stdlib (`glob`, `fnmatch`, `json`, `tempfile`), Typer, pytest.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§6 Grids and cache; §7 Arming requires a backtest of the current file hash)

**Index:** `docs/superpowers/plans/README.md` (contracts: Plans 09/10 `fenrir.backtest` grid/cache, plan 03 `data_version`, plan 05 `list_accounts`/`rules_path`, plan 07 loader)

## Global Constraints

- Python 3.12, `uv`; `uv run pytest -q`; `uv run ruff check . && uv run ruff format --check .`.
- Functional core, imperative shell: only `grid.py`'s glob/load and `cache.py`'s file reads/writes do I/O; key computation and contract filtering are pure.
- CLI shapes (spec §6): `fenrir backtest strategies/*.py --account lucid-pro-50k`, `fenrir backtest strategies/orb.py --account 'lucid-*'`, `--contract MNQ`.
- `contracts` omitted = both symbols of the strategy's `MARKET` (NQ → NQ, MNQ; ES → ES, MES).
- Cache key = `sha256(strategy bytes, rules bytes, data_version, contract, holdout_months, include_holdout)`, computed by plan 09's `report_key` from the file hashes; results live in `data/results/<key>.json`.
- Contracts verbatim from the index: `GridItem`, `expand_grid`, `cache_key`, `cached_run`, `find_report`, `list_reports`.
- Commits: Conventional Commits, scope `backtest` / `cli`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A strategy or account glob that matches nothing (typo `--account 'lucd-*'`) → `ValueError` naming the pattern, not a silent empty run. Tests in Task 1.
2. `--contract MNQ` with only ES strategies → `ValueError("empty grid ...")`, not "0 results" printed as success. Test in Task 1 (`test_contract_that_fits_no_strategy_is_an_error`).
3. Rules YAML edited, strategy edited, or new data pulled after a cached run → the next run recomputes; a stale report is never returned. Test in Task 2 (`test_any_input_change_misses_the_cache`).
4. A crash mid-write leaves a temp file behind → `list_reports` ignores it and no half-written `<key>.json` ever exists. Test in Task 2 (`test_write_is_atomic_and_temp_files_ignored`).
5. A strategy edited while its backtest runs → the report is stored under the key of the bytes that actually ran, so the edited file's next lookup misses instead of returning the old report. Test in Task 2 (`test_report_stored_under_its_own_key`).

`src/fenrir/backtest/grid.py`:

```python
"""Strategy globs × account globs × contracts → backtest runs. Shell: globs files, reads MARKET."""

from collections.abc import Sequence
from dataclasses import dataclass
from fnmatch import fnmatchcase
from glob import glob
from pathlib import Path

from fenrir.core.instruments import Instruments, load_instruments, spec
from fenrir.rules.loader import list_accounts
from fenrir.settings import Settings
from fenrir.strategy.loader import load_strategy


@dataclass(frozen=True, slots=True)
class GridItem:
    strategy_path: Path
    account_id: str
    contract: str


def contracts_for(market: str, contracts: Sequence[str] | None, instruments: Instruments) -> tuple[str, ...]:
    symbols = [s.symbol for s in instruments.specs if s.series == market]
    return tuple(symbols if contracts is None else [c for c in contracts if c in symbols])


def _strategy_paths(pattern: str) -> list[Path]:
    paths = sorted(Path(p) for p in glob(pattern))
    if not paths:
        raise ValueError(f"no strategy files match {pattern!r}")
    return paths


def _accounts(pattern: str, known: tuple[str, ...]) -> list[str]:
    matched = [a for a in known if fnmatchcase(a, pattern)]
    if not matched:
        raise ValueError(f"no rules accounts match {pattern!r}")
    return matched


def expand_grid(
    strategy_globs: Sequence[str],
    account_globs: Sequence[str],
    contracts: Sequence[str] | None,
    settings: Settings,
) -> tuple[GridItem, ...]:
    instruments = load_instruments()
    for c in contracts or ():
        spec(instruments, c)  # raises ValueError on an unknown symbol
    paths = list(dict.fromkeys(p for g in strategy_globs for p in _strategy_paths(g)))
    known = list_accounts(settings.rules_dir)
    accounts = list(dict.fromkeys(a for g in account_globs for a in _accounts(g, known)))
    markets = {p: load_strategy(p).market for p in paths}
    items = tuple(
        GridItem(p, a, c)
        for p in paths
        for a in accounts
        for c in contracts_for(markets[p], contracts, instruments)
    )
    if not items:
        raise ValueError(f"empty grid: no strategy trades {', '.join(contracts or ())}")
    return items
```

`src/fenrir/backtest/cache.py`:

```python
"""Backtest results cached in data/results/<key>.json. Shell."""

import json
import os
import tempfile
from collections.abc import Callable

from fenrir.backtest.grid import GridItem
from fenrir.backtest.report import Report, report_key
from fenrir.backtest.run import run_backtest
from fenrir.data.store import data_version
from fenrir.rules.loader import rules_path
from fenrir.settings import Settings
from fenrir.strategy.loader import file_hash


def _results(settings: Settings):
    return settings.data_dir / "results"


def cache_key(item: GridItem, settings: Settings, include_holdout: bool) -> str:
    return report_key(
        file_hash(item.strategy_path),
        file_hash(rules_path(item.account_id, settings.rules_dir)),
        data_version(settings.data_dir),
        item.contract,
        settings.holdout_months,
        include_holdout,
    )


def cached_run(
    item: GridItem,
    settings: Settings,
    *,
    include_holdout: bool,
    on_progress: Callable[[int, int], None] | None = None,
) -> Report:
    path = _results(settings) / f"{cache_key(item, settings, include_holdout)}.json"
    if path.exists():
        return json.loads(path.read_text())
    report = run_backtest(
        item.strategy_path,
        item.account_id,
        item.contract,
        settings,
        include_holdout=include_holdout,
        on_progress=on_progress,
    )
    path.parent.mkdir(parents=True, exist_ok=True)
    # Stored under the key of the bytes that ran: a file edited mid-run misses next time.
    fd, tmp = tempfile.mkstemp(dir=path.parent, suffix=".tmp")
    with os.fdopen(fd, "w") as f:
        json.dump(report, f)
    os.replace(tmp, path.parent / f"{report['key']}.json")
    return report


def list_reports(settings: Settings) -> tuple[Report, ...]:
    reports = [json.loads(p.read_text()) for p in _results(settings).glob("*.json")]
    return tuple(sorted(reports, key=lambda r: r["created_at"], reverse=True))


def find_report(settings: Settings, strategy_hash: str, account_id: str) -> Report | None:
    return next(
        (r for r in list_reports(settings) if r["strategy_hash"] == strategy_hash and r["account"] == account_id),
        None,
    )
```

def backtest(strategies: Strategies, account: Accounts, contract: Contracts = None, as_json: AsJson = False) -> None:
    """Backtest on the tuning period only (never sees the hold-out). Cached by file hashes."""
    _run(strategies, account, contract, as_json, include_holdout=False)


def evaluate(strategies: Strategies, account: Accounts, contract: Contracts = None, as_json: AsJson = False) -> None:
    """Backtest on the tuning and hold-out periods, side by side. Cached by file hashes."""
    _run(strategies, account, contract, as_json, include_holdout=True)
