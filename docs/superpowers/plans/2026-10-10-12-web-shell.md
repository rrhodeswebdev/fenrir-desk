# Web Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Vite + React + TypeScript app in `web/` with TanStack Router (code-based) and TanStack Query, Tailwind CSS v4 and shadcn/ui, a token-aware API client, a nav bar with all seven pages as empty stubs, the brand palette as shadcn theme variables, a dev proxy to `fenrir serve`, a typecheck script, and a Playwright smoke test against the real server.

**Architecture:** `web/src/api.ts` is the only code that knows about the session token: it reads `<meta name="fenrir-token">` (or, in dev, `GET /api/dev-token`) and wraps `fetch`/WebSocket URLs. `web/src/router.tsx` assembles one route per file in `web/src/routes/`. `npm run build` writes `web/dist/`, which `fenrir serve` (plan 11) serves with the token injected. Styling is Tailwind utility classes only; UI primitives come from shadcn/ui, generated into `web/src/components/ui/` by the shadcn CLI, themed by CSS variables in `web/src/index.css`.

**Tech Stack:** Node 22, Vite, React 19, TypeScript (strict), Tailwind CSS v4 (`@tailwindcss/vite`), shadcn/ui (Radix primitives, `npx shadcn@latest`), `@tanstack/react-router`, `@tanstack/react-query`, `@playwright/test`. Fonts: Chakra Petch + IBM Plex Mono (Google Fonts).

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§10 pages, §2 functional style, §12 frontend testing)

**Index:** `docs/superpowers/plans/README.md` (contracts: "Plan 12 — web", "Plan 11 — server")

## Global Constraints

- Pages (§10): Workbench `/`, Rules `/rules`, Data `/data`, Backtests `/backtests` and `/backtests/$key`, Strategies `/strategies`, Live `/live`, Settings `/settings`.
- `apiFetch<T>(path, init?)` adds `X-Fenrir-Token`, throws `ApiError` (status + body text) on non-2xx. `wsUrl(path)` adds `?token=`. `token()` returns the token.
- Each page file `web/src/routes/<page>.tsx` exports `<page>Route` made with `createRoute`; `web/src/router.tsx` assembles the tree.
- Query keys: `['<area>', ...args]`.
- Dev: Vite on port 5173 (strict) proxies `/api` and `/ws` to `127.0.0.1:8000`; run the server with `fenrir serve --dev`.
- React: function components and hooks only; server state only in TanStack Query.
- Typecheck: `npm --prefix web run typecheck`. Playwright tests live in `web/e2e/` and run against `fenrir serve` with `FENRIR_DATA_DIR=tests/fixtures/e2e`.
- Styling: Tailwind utility classes and shadcn/ui components only. No hand-written CSS classes outside `web/src/index.css`, no inline `style={{}}` except values computed at runtime. Components in `web/src/components/ui/` are generated by `npx shadcn@latest add <name>` and not hand-edited (theming lives in `index.css`). Import them as `@/components/ui/<name>`; `cn()` lives in `@/lib/utils`.
- Theme: dark by default (`<html class="dark">`). Palette from `assets/brand/README.md` — dark: Night `#0E1116`, Ice `#E8EEF4`, Steel `#C9D3DD`, Slate `#8FA0B2`, Ember `#E0A33A`; light: Frost `#EEF1F4`, Ink `#141A22`, Ember Deep `#8A5A0E`. **Token values are provisional:** a design pass with the impeccable skill writes `DESIGN.md`; if `DESIGN.md` exists when this plan runs, use its tokens instead of the values below.
- Charts (later plans) use `lightweight-charts`, never shadcn charts/Recharts, and read colors from the `--chart-*` CSS variables.

## Review Focus

1. **Token missing from the page** (UI opened from `vite preview` or a stale cached `index.html`) — the user should see a clear "No session token — open the app from `fenrir serve`" message, not a page of silent 401s. Test: `shows an error when the token is missing` (Task 2, Playwright against a page without the meta tag via route interception).
2. **Non-JSON error bodies** (FastAPI 500 returns text) — `apiFetch` must surface status and body, not throw a JSON parse error. Covered by `ApiError` carrying `body` text; exercised in Task 2's `api error surfaces status` Playwright test.
3. **Deep link reload** (`/backtests/abc` refreshed) — must render the app, not a 404. Test: `deep link loads` (Task 3).
4. **WebSocket URL under https or a non-root path** — `wsUrl` must switch `http→ws`/`https→wss` and keep the host. Test: `wsUrl uses ws scheme and token` (Task 2, evaluated in the browser).
5. **Unknown route** — shows a "Not found" page inside the shell with nav still usable. Test: `unknown route shows not found` (Task 3).

- [ ] **Step 4: Write the API client**

`web/src/api.ts`:

```ts
let current = document.querySelector<HTMLMetaElement>('meta[name="fenrir-token"]')?.content ?? ''

/** In dev the Vite page has no injected meta tag, so ask `fenrir serve --dev` for it. */
export async function initToken(): Promise<void> {
  if (current || !import.meta.env.DEV) return
  const res = await fetch('/api/dev-token')
  if (res.ok) current = ((await res.json()) as { token: string }).token
}

export const token = (): string => current

export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly body: string,
  ) {
    super(`${status}: ${body}`)
  }
}

export async function apiFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const headers = new Headers(init.headers)
  headers.set('X-Fenrir-Token', current)
  if (init.body !== undefined && !headers.has('Content-Type')) headers.set('Content-Type', 'application/json')
  const res = await fetch(path, { ...init, headers })
  if (!res.ok) throw new ApiError(res.status, await res.text())
  return (await res.json()) as T
}

export function wsUrl(path: string): string {
  const url = new URL(path, window.location.href)
  url.protocol = url.protocol === 'https:' ? 'wss:' : 'ws:'
  url.searchParams.set('token', current)
  return url.toString()
}
```

```tsx
              buttonVariants({ variant: 'ghost', size: 'sm' }),
              'text-muted-foreground data-[status=active]:text-primary',
            )}
          >
            {name}
          </Link>
        ))}
      </nav>
      <main className="p-5">
        {token() ? (
          <Outlet />
        ) : (
          <Alert variant="destructive">
            <AlertTitle>No session token</AlertTitle>
            <AlertDescription>
              Open the app from <code>fenrir serve</code>.
            </AlertDescription>
          </Alert>
        )}
      </main>
    </div>
  )
}

export const rootRoute = createRootRoute({
  component: Shell,
  notFoundComponent: () => <h1>Not found</h1>,
})
```
