# Terminal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Workbench page's left pane is a working shell (where the user runs `claude`), connected over `/ws/terminal` to a PTY in the Python server that starts in the repo directory and never sees the session token.

**Architecture:** Pure core in `fenrir.server.terminal`: `child_env` (scrubs the token and every `FENRIR_*` var), `shell_argv`, and `parse_message` (client JSON → `Input | Resize`). Shell in `fenrir.server.ptyproc`: `PosixPty` (stdlib `pty.fork` + event-loop reader) and `WinPty` (`pywinpty`), both exposing `read/write/resize/close`. The WebSocket handler in `fenrir.server.routes.terminal` only forwards bytes. The browser side is one React component wrapping xterm.js.

**Tech Stack:** Python stdlib `pty`/`termios`/`fcntl`, `pywinpty` (Windows only), FastAPI WebSocket, `@xterm/xterm`, `@xterm/addon-fit`, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§7 built-in terminal, security requirements, arming is user-only)

**Index:** `docs/superpowers/plans/README.md` (contracts: "Plan 11 — server", "Plan 12 — web")

## Global Constraints

- PTY: `pywinpty` on Windows, stdlib `pty` elsewhere; in Docker this is always Linux.
- The shell starts in the repo directory (the server's working directory).
- The PTY's environment never contains the session token, so Claude in the terminal cannot call the arm endpoint. Every `FENRIR_*` variable is also removed.
- The WebSocket at `/ws/terminal` calls `check_ws` before `accept()`; bad token or foreign `Origin` → close code 4401.
- Protocol: client → server text frames `{"type":"input","data":"..."}` or `{"type":"resize","cols":N,"rows":M}`; server → client binary frames of raw PTY output.
- Functional core, imperative shell: the handler only forwards.

## Review Focus

1. **Token leaking under another variable name** (e.g. a user exports `TOKEN=<session token>` in `.env` or the parent shell) — the child env must drop any variable whose value contains the token. Test: `test_child_env_drops_any_var_holding_token` (Task 1).
2. **Browser tab closed with `claude` running** — the shell and its jobs must die; no orphan processes per reconnect. Test: `test_disconnect_kills_shell` (Task 2).
3. **User types `exit`** — the WebSocket closes cleanly and the UI says the terminal disconnected, instead of a frozen pane. Test: `test_shell_exit_closes_socket` (Task 2); UI message in Task 3.
4. **Malformed or hostile client frames** (non-JSON, unknown `type`, `cols: 10**9`, negative rows) — ignored or clamped, never a server crash or `ioctl` overflow. Test: `test_parse_message_*` (Task 1).
5. **Empty token** (misconfigured start) — `child_env` must not drop every variable just because `"" in value` is always true. Test: `test_child_env_empty_token_keeps_env` (Task 1).

`src/fenrir/server/terminal.py`:

```python
"""Pure core of the browser terminal: child environment, shell choice, client messages."""

import json
from collections.abc import Mapping
from dataclasses import dataclass


@dataclass(frozen=True, slots=True)
class Input:
    data: str


@dataclass(frozen=True, slots=True)
class Resize:
    cols: int
    rows: int


def child_env(env: Mapping[str, str], token: str) -> dict[str, str]:
    """The shell's environment: no FENRIR_* settings and nothing holding the session token."""
    kept = {
        k: v
        for k, v in env.items()
        if not k.startswith("FENRIR_") and not (token and token in v)
    }
    return kept | {"TERM": "xterm-256color"}


def shell_argv(env: Mapping[str, str], platform: str) -> list[str]:
    if platform == "win32":
        return ["powershell.exe"]
    return [env.get("SHELL", "/bin/bash")]


def _clamp(n: int) -> int:
    return max(1, min(n, 1000))


def parse_message(text: str) -> Input | Resize | None:
    try:
        msg = json.loads(text)
    except ValueError:
        return None
    if not isinstance(msg, dict):
        return None
    match msg.get("type"):
        case "input" if isinstance(msg.get("data"), str):
            return Input(msg["data"])
        case "resize" if isinstance(msg.get("cols"), int) and isinstance(msg.get("rows"), int):
            return Resize(_clamp(msg["cols"]), _clamp(msg["rows"]))
    return None
```

`src/fenrir/server/ptyproc.py`:

```python
"""Imperative shell: a pseudo-terminal running the user's shell."""

import asyncio
import contextlib
import os
import pty
import signal
import struct
import sys
from pathlib import Path


class PosixPty:
    def __init__(self, argv: list[str], cwd: Path, env: dict[str, str]) -> None:
        pid, fd = pty.fork()  # setsid + controlling tty in the child
        if pid == 0:
            os.chdir(cwd)
            os.execvpe(argv[0], argv, env)
        self.pid, self.fd = pid, fd
        os.set_blocking(fd, False)
        self._chunks: asyncio.Queue[bytes] = asyncio.Queue()
        self._loop = asyncio.get_running_loop()
        self._loop.add_reader(fd, self._on_readable)

    def _on_readable(self) -> None:
        try:
            data = os.read(self.fd, 65536)
        except OSError:  # EIO once the shell has exited
            data = b""
        if not data:
            self._loop.remove_reader(self.fd)
        self._chunks.put_nowait(data)

    async def read(self) -> bytes:
        return await self._chunks.get()

    def write(self, data: str) -> None:
        # shortcut: a paste larger than the PTY buffer raises BlockingIOError; loop on partial writes if that bites
        os.write(self.fd, data.encode())

    def resize(self, cols: int, rows: int) -> None:
        import fcntl  # POSIX-only; imported here so this file still imports on Windows
        import termios

        fcntl.ioctl(self.fd, termios.TIOCSWINSZ, struct.pack("HHHH", rows, cols, 0, 0))

    def close(self) -> None:
        self._loop.remove_reader(self.fd)
        os.close(self.fd)  # hangs up the session: background jobs get SIGHUP
        with contextlib.suppress(ProcessLookupError):
            os.killpg(self.pid, signal.SIGKILL)
        os.waitpid(self.pid, 0)


class WinPty:
    def __init__(self, argv: list[str], cwd: Path, env: dict[str, str]) -> None:
        from winpty import PtyProcess

        self.proc = PtyProcess.spawn(argv, cwd=str(cwd), env=env)

    async def read(self) -> bytes:
        try:
            return (await asyncio.to_thread(self.proc.read, 65536)).encode()
        except EOFError:
            return b""

    def write(self, data: str) -> None:
        self.proc.write(data)

    def resize(self, cols: int, rows: int) -> None:
        self.proc.setwinsize(rows, cols)

    def close(self) -> None:
        self.proc.terminate(force=True)


def open_pty(argv: list[str], cwd: Path, env: dict[str, str]) -> PosixPty | WinPty:
    return WinPty(argv, cwd, env) if sys.platform == "win32" else PosixPty(argv, cwd, env)
```

```python
import asyncio
import contextlib
import os
import sys
from pathlib import Path

from fastapi import APIRouter, WebSocket, WebSocketDisconnect

from fenrir.server.auth import check_ws
from fenrir.server.ptyproc import open_pty
from fenrir.server.terminal import Input, Resize, child_env, parse_message, shell_argv

router = APIRouter()


@router.websocket("/ws/terminal")
async def terminal(ws: WebSocket) -> None:
    if not check_ws(ws):
        await ws.close(code=4401)
        return
    await ws.accept()
    term = open_pty(
        shell_argv(os.environ, sys.platform), Path.cwd(), child_env(os.environ, ws.app.state.token)
    )

    async def pump() -> None:
        while chunk := await term.read():
            await ws.send_bytes(chunk)
        await ws.close()

    output = asyncio.create_task(pump())
    try:
        while True:
            match parse_message(await ws.receive_text()):
                case Input(data):
                    term.write(data)
                case Resize(cols, rows):
                    term.resize(cols, rows)
    except (WebSocketDisconnect, RuntimeError):  # RuntimeError: socket already closed by pump
        pass
    finally:
        output.cancel()
        with contextlib.suppress(asyncio.CancelledError):
            await output
        term.close()
```

```tsx
import { FitAddon } from '@xterm/addon-fit'
import { Terminal as XTerm } from '@xterm/xterm'
import '@xterm/xterm/css/xterm.css'
import { useEffect, useRef } from 'react'
import { wsUrl } from './api'

export function Terminal() {
  const el = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const term = new XTerm({
      fontFamily: "'IBM Plex Mono', ui-monospace, monospace",
      theme: { background: '#0e1116', foreground: '#e8eef4', cursor: '#e0a33a' },
    })
    const fit = new FitAddon()
    term.loadAddon(fit)
    term.open(el.current!)
    fit.fit()

    const ws = new WebSocket(wsUrl('/ws/terminal'))
    ws.binaryType = 'arraybuffer'
    const send = (msg: object) => ws.readyState === WebSocket.OPEN && ws.send(JSON.stringify(msg))
    ws.onopen = () => send({ type: 'resize', cols: term.cols, rows: term.rows })
    ws.onmessage = (e) => term.write(new Uint8Array(e.data as ArrayBuffer))
    ws.onclose = () => term.write('\r\n[terminal disconnected — reload the page to start a new shell]\r\n')

    const input = term.onData((data) => send({ type: 'input', data }))
    const resize = term.onResize(({ cols, rows }) => send({ type: 'resize', cols, rows }))
    const observer = new ResizeObserver(() => fit.fit())
    observer.observe(el.current!)

    return () => {
      observer.disconnect()
      input.dispose()
      resize.dispose()
      ws.close()
      term.dispose()
    }
  }, [])

  return <div ref={el} className="terminal" />
}
```
