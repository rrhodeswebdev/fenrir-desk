# Rules Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rules page that lists every Lucid account type, warns when an account's `verified_on` is more than 30 days old, and edits an account through a field-by-field form that the server validates before writing the YAML.

**Architecture:** `src/fenrir/server/routes/rules.py` holds pure helpers (`staleness`, `field_errors`, `validate`) and three thin handlers over plan 05's loader. `GET` returns the account as JSON (`AccountRules.model_dump(mode="json")`); `PUT` takes that JSON, validates it with `AccountRules` (unknown keys rejected), refuses a rename, and writes `dump_account` output atomically. A 422 carries pydantic's errors as `{loc, msg}` so the form shows each message next to its input. The form keeps its state as one immutable object updated by a pure `setIn(obj, path, value)`; the server stays the only validator.

**Tech Stack:** Python 3.12, FastAPI, pydantic v2, PyYAML, pytest; React 19, TanStack Router + Query, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§4 Rules library, §10 Rules row: "validated edit form that writes the YAML")

**Index:** `docs/superpowers/plans/README.md` (plan 05 loader contract, plan 11 server conventions, plan 12 web conventions, "Plan 15 — rules API")

## Global Constraints

- Functional core, imperative shell; FastAPI handlers only parse and forward.
- Every `/api` router is registered with `dependencies=[Depends(require_token)]`.
- Loading validates against the schema and rejects unknown keys (spec §4); the server never writes a file that fails `AccountRules` validation.
- Staleness warning when `verified_on` is over 30 days old (spec §10): 30 days is fine, 31 is stale. `verified_on: null` means never verified and also gets the warning.
- Values are entered from Lucid's own site, not third-party summaries (spec §4); the form says so.
- React: function components + hooks; server state only in TanStack Query; query keys `['rules']`, `['rules', id]`. Form state is one immutable object; every change goes through `setIn`.
- Commits: Conventional Commits, scope `server` or `web`; every message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A YAML file on disk is invalid** (hand-edited typo): the list still loads, the bad account shows "Invalid file", and its editor explains that it must be fixed by hand. Tests: `test_list_survives_a_broken_file`, `test_get_broken_file_has_no_rules` (Task 1).
2. **Save with a bad value deep in the tree** (negative funded drawdown): 422 with `loc == ["funded", "max_drawdown", "amount"]`, the message shown next to that input, and the file on disk unchanged. Tests: `test_put_invalid_is_422_with_field_loc_and_file_unchanged` (Task 1), `invalid value shows the field error` (Task 3).
3. **Save that changes `firm` or `account`** would leave the old file name holding another account's rules, so it is rejected with an error on `["account"]`. Test: `test_put_rename_is_rejected` (Task 1).
4. **Unknown account id or a non-object body**: 404 and no file is created; a JSON array body is 422. Tests: `test_put_unknown_account_is_404`, `test_put_non_object_is_422` (Task 1).
5. **e2e saves must not touch the committed `rules/`**: Playwright serves a fresh, gitignored copy. Covered by the config change in Task 3, Step 1.

```python
"""Rules API: list Lucid account types, read one account as JSON, save form edits after validation."""

from datetime import date
from typing import Any

from fastapi import APIRouter, Body, HTTPException, Request
from fastapi.responses import JSONResponse
from pydantic import ValidationError

from fenrir.rules.loader import account_id, dump_account, list_accounts, load_account, rules_path
from fenrir.rules.schema import AccountRules
from fenrir.settings import Settings

STALE_AFTER_DAYS = 30

router = APIRouter(prefix="/api/rules")


def staleness(verified_on: date | None, today: date) -> dict:
    if verified_on is None:  # never checked against Lucid's site
        return {"verified_on": None, "age_days": None, "stale": True}
    age = (today - verified_on).days
    return {"verified_on": verified_on.isoformat(), "age_days": age, "stale": age > STALE_AFTER_DAYS}


def field_errors(e: ValidationError) -> list[dict]:
    return [{"loc": list(err["loc"]), "msg": err["msg"]} for err in e.errors()]


def validate(data: dict[str, Any], aid: str) -> AccountRules | list[dict]:
    """The posted rules as a model, or per-field errors whose `loc` is a path into `data`."""
    try:
        rules = AccountRules.model_validate(data)
    except ValidationError as e:
        return field_errors(e)
    if account_id(rules) != aid:
        return [{"loc": ["account"], "msg": f"firm/account give {account_id(rules)}, expected {aid}. Renaming is not supported."}]
    return rules


def _row(aid: str, s: Settings, today: date) -> dict:
    try:
        return {"id": aid, "error": None, **staleness(load_account(aid, s.rules_dir).verified_on, today)}
    except ValueError as e:
        return {"id": aid, "error": str(e), "verified_on": None, "age_days": None, "stale": None}


def _known(aid: str, s: Settings) -> None:
    if aid not in list_accounts(s.rules_dir):  # also blocks path tricks: only existing ids reach rules_path
        raise HTTPException(404, f"Unknown account {aid}")


@router.get("")
def list_rules(request: Request) -> list[dict]:
    s: Settings = request.app.state.settings
    return [_row(aid, s, date.today()) for aid in list_accounts(s.rules_dir)]


@router.get("/{aid}")
def get_rules(aid: str, request: Request) -> dict:
    s: Settings = request.app.state.settings
    _known(aid, s)
    try:
        rules = load_account(aid, s.rules_dir)
    except ValueError as e:
        return {"id": aid, "error": str(e), "verified_on": None, "age_days": None, "stale": None, "rules": None}
    return {"id": aid, "error": None, **staleness(rules.verified_on, date.today()), "rules": rules.model_dump(mode="json")}


@router.put("/{aid}")
def save_rules(aid: str, request: Request, data: dict[str, Any] = Body(...)):
    s: Settings = request.app.state.settings
    _known(aid, s)
    result = validate(data, aid)
    if isinstance(result, list):
        return JSONResponse({"detail": "The rules do not validate.", "errors": result}, status_code=422)
    path = rules_path(aid, s.rules_dir)
    tmp = path.with_suffix(".yaml.tmp")
    tmp.write_text(dump_account(result))
    tmp.replace(path)  # atomic: a crash mid-save never leaves a half-written rules file
    return {"id": aid, "error": None, **staleness(result.verified_on, date.today())}
```

```ts
import { ApiError } from './api'

/** FastAPI errors arrive as `{"detail": ...}`; show the detail, not the raw JSON. */
export function errorText(e: unknown): string {
  if (!(e instanceof ApiError)) return String(e)
  try {
    const detail = (JSON.parse(e.body) as { detail?: unknown }).detail
    return typeof detail === 'string' ? detail : JSON.stringify(detail)
  } catch {
    return e.message
  }
}
```

```ts
import { ApiError } from './api'

export type Path = readonly (string | number)[]
export type FieldError = { loc: Path; msg: string }

type Node = Record<string | number, unknown>

/** A copy of `obj` with the value at `path` replaced. Nothing is mutated; untouched branches are shared. */
export function setIn<T>(obj: T, path: Path, value: unknown): T {
  if (path.length === 0) return value as T
  const [head, ...rest] = path
  const node = (obj ?? {}) as Node
  return { ...node, [head]: setIn(node[head], rest, value) } as T
}

export function getIn(obj: unknown, path: Path): unknown {
  return path.reduce<unknown>((o, k) => (o == null ? undefined : (o as Node)[k]), obj)
}

const key = (path: Path) => path.join('.')

/** Server messages whose pydantic `loc` is exactly this input's path. */
export function errorsAt(errors: FieldError[], path: Path): string[] {
  return errors.filter((e) => key(e.loc) === key(path)).map((e) => e.msg)
}

/** The `{loc, msg}` list from a 422 save, or [] for any other error. */
export function fieldErrors(e: unknown): FieldError[] {
  if (!(e instanceof ApiError) || e.status !== 422) return []
  try {
    return (JSON.parse(e.body) as { errors?: FieldError[] }).errors ?? []
  } catch {
    return []
  }
}
```

```tsx
function Freshness({ row }: { row: RuleRow }) {
  if (row.error) return <span className="error">Invalid file</span>
  if (row.stale)
    return (
      <span className="error">
        {row.verified_on ? `Verified ${row.age_days} days ago` : 'Never verified'}: re-check on Lucid's site
      </span>
    )
  return <span>Verified {row.verified_on}</span>
}

function RuleEditor({ id }: { id: string }) {
  const qc = useQueryClient()
  const url = `/api/rules/${encodeURIComponent(id)}`
  const detail = useQuery({ queryKey: ['rules', id], queryFn: () => apiFetch<RuleDetail>(url) })
  const [draft, setDraft] = useState<Rules | null>(null) // null = unchanged from the server copy
  const save = useMutation({
    mutationFn: (rules: Rules) => apiFetch<RuleRow>(url, { method: 'PUT', body: JSON.stringify(rules) }),
    onSuccess: () => {
      setDraft(null)
      void qc.invalidateQueries({ queryKey: ['rules'] })
    },
  })
  if (!detail.data) return <p>{detail.error ? errorText(detail.error) : 'Loading…'}</p>
  const server = detail.data.rules
  if (!server)
    return (
      <p className="error" role="alert">
        This file does not validate, so it cannot be edited here: {detail.data.error}. Fix it by hand in rules/lucid/.
      </p>
    )
  const errors = fieldErrors(save.error)
  const f: Form = { rules: draft ?? server, errors, set: (path, value) => setDraft((d) => setIn(d ?? server, path, value)) }
  return (
    <section aria-label={`Edit ${id}`}>
      <h2>{id}</h2>
      {detail.data.stale && (
        <p className="error">
          {detail.data.verified_on ? `Verified ${detail.data.age_days} days ago.` : 'Never verified.'} Re-check every value on
          Lucid's own site, then update Verified on.
        </p>
      )}
      <p>Enter values from Lucid's own site, not third-party summaries.</p>
      <form
        onSubmit={(e) => {
          e.preventDefault()
          save.mutate(f.rules)
        }}
      >
        <RulesForm f={f} />
        <button type="submit" disabled={draft === null || save.isPending}>
          Save
        </button>
        {save.error && (
          <div className="error" role="alert">
            {errorText(save.error)}
            <ul>
              {errors.map((e) => (
                <li key={`${e.loc.join('.')}:${e.msg}`}>
                  {e.loc.join('.') || 'rules'}: {e.msg}
                </li>
              ))}
            </ul>
          </div>
        )}
        {save.isSuccess && draft === null && <p role="status">Saved.</p>}
      </form>
    </section>
  )
}

function RulesPage() {
  const [selected, setSelected] = useState<string | null>(null)
  const rows = useQuery({ queryKey: ['rules'], queryFn: () => apiFetch<RuleRow[]>('/api/rules') })
  return (
    <>
      <h1>Rules</h1>
      {rows.error && <p className="error">{errorText(rows.error)}</p>}
      <table>
        <thead>
          <tr>
            <th scope="col">Account</th>
            <th scope="col">Verified</th>
            <th scope="col">
              <span className="visually-hidden">Actions</span>
            </th>
          </tr>
        </thead>
        <tbody>
          {(rows.data ?? []).map((r) => (
            <tr key={r.id}>
              <td>{r.id}</td>
              <td>
                <Freshness row={r} />
              </td>
              <td>
                <button type="button" onClick={() => setSelected(r.id)} aria-label={`Edit ${r.id}`}>
                  Edit
                </button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
      {selected && <RuleEditor key={selected} id={selected} />}
    </>
  )
}
```
