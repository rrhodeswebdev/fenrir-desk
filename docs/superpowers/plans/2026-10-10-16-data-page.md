# Data Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Data page that shows downloaded coverage and gaps for ES and NQ, a Pull button that runs `fenrir data pull` in the background with visible status and log, and the rollover table with the current front month marked.

**Architecture:** The pull runs as a child process of the server (`fenrir data pull`, the same command the CLI user runs), so the server never imports LSE code and a crashing pull cannot take the server down. `fenrir.server.pull` holds a pure `pull_status` and a thin `PullRunner` shell that allows one child at a time and logs to `data/pull.log`. `routes/data.py` forwards to plan 03's `coverage` and plan 01's `load_instruments`/`front_month`. The page polls every 2 s only while a pull is running.

**Tech Stack:** Python 3.12, FastAPI, pytest; React 19, TanStack Router + Query. UI: Tailwind CSS v4 utility classes + shadcn/ui components (`@/components/ui/*`, set up in plan 12; add missing ones with `npx shadcn@latest add`); no custom CSS classes or inline styles except runtime-computed values.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§3 Market data, §10 Data row)

**Index:** `docs/superpowers/plans/README.md` (plan 01 instruments contract, plan 03 `coverage`/CLI contract, plan 11 server conventions, plan 12 web conventions)

## Global Constraints

- Functional core, imperative shell; FastAPI handlers only parse and forward.
- Every `/api` router is registered with `dependencies=[Depends(require_token)]`.
- The fetch step (plan 03's `fenrir data pull`) is the only code that knows about LSE (spec §3); this plan only runs it.
- MES and MNQ use ES and NQ prices: coverage is per series (`ES`, `NQ`), not per contract.
- React: function components + hooks; server state only in TanStack Query; query key `['data']`.
- Commits: Conventional Commits, scope `server` or `web`; every message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Fresh clone, no data yet** — the page loads with 0 days per series and an empty gap list, not a 500. Test: `test_overview_on_empty_data_dir` (Task 2).
2. **Pull clicked twice** — the second click gets 409 and no second process starts (two pulls would write the same Parquet files). Tests: `test_second_start_while_running_is_refused` (Task 1), `test_pull_twice_is_409` (Task 2).
3. **Pull fails** (no LSE key, network down) — state `error` with the last log lines shown, so the user sees why. Test: `test_failed_pull_reports_error_and_log` (Task 1).
4. **Today outside the rollover calendar** (calendar not extended) — the front month shows "—", not a 500. Test: `test_front_months_outside_calendar_is_none` (Task 2).
5. **Very long pull log** — only the last 20 lines are sent. Test: `test_log_tail_is_last_20_lines` (Task 1).

import time

from fenrir.server.pull import PullRunner, pull_command, pull_status


def wait_for(cond, timeout: float = 10.0) -> None:
    end = time.monotonic() + timeout
    while time.monotonic() < end:
        if cond():
            return
        time.sleep(0.02)
    raise AssertionError("condition not met in time")


def py(code: str) -> list[str]:
    return [sys.executable, "-c", code]


def test_pull_status_states():
    assert pull_status(None, None, [])["state"] == "idle"
    assert pull_status("t", None, [])["state"] == "running"
    assert pull_status("t", 0, [])["state"] == "done"
    assert pull_status("t", 2, ["x"]) == {"state": "error", "started_at": "t", "returncode": 2, "log_tail": ["x"]}


def test_pull_command_runs_the_cli():
    assert pull_command()[-2:] == ["data", "pull"]
    assert pull_command()[0] == sys.executable


def test_successful_pull_reports_done(tmp_path):
    runner = PullRunner(py("print('pulled ES')"), tmp_path / "pull.log")
    assert runner.status()["state"] == "idle"
    assert runner.start() is True
    wait_for(lambda: runner.status()["state"] == "done")
    assert runner.status()["log_tail"] == ["pulled ES"]


def test_failed_pull_reports_error_and_log(tmp_path):
    runner = PullRunner(py("import sys; print('missing FENRIR_LSE_API_KEY'); sys.exit(1)"), tmp_path / "pull.log")
    runner.start()
    wait_for(lambda: runner.status()["state"] == "error")
    assert runner.status()["log_tail"] == ["missing FENRIR_LSE_API_KEY"]


def test_second_start_while_running_is_refused(tmp_path):
    runner = PullRunner(py("import time; time.sleep(1)"), tmp_path / "pull.log")
    assert runner.start() is True
    assert runner.start() is False
    wait_for(lambda: runner.status()["state"] == "done")
    assert runner.start() is True  # allowed again once finished


def test_log_tail_is_last_20_lines(tmp_path):

    runner.start()
    wait_for(lambda: runner.status()["state"] == "done")
    assert runner.status()["log_tail"] == [str(i) for i in range(30, 50)]

`src/fenrir/server/pull.py`:

```python
"""Runs `fenrir data pull` as a child process, one at a time, for the Data page."""

import subprocess
import sys
import threading
from collections.abc import Sequence
from datetime import UTC, datetime
from pathlib import Path

TAIL_LINES = 20


def pull_status(started_at: str | None, returncode: int | None, log_tail: list[str]) -> dict:
    if started_at is None:
        state = "idle"
    elif returncode is None:
        state = "running"
    else:
        state = "done" if returncode == 0 else "error"
    return {"state": state, "started_at": started_at, "returncode": returncode, "log_tail": log_tail}


def pull_command() -> list[str]:
    # The server's own interpreter, so the child uses the same venv without relying on PATH.
    return [sys.executable, "-c", "from fenrir.cli.main import app; app()", "data", "pull"]


class PullRunner:
    # shortcut: state lives in memory, so a server restart forgets a pull still running; persist the pid if that bites
    def __init__(self, cmd: Sequence[str], log_path: Path) -> None:
        self._cmd = list(cmd)
        self._log = log_path
        self._lock = threading.Lock()
        self._proc: subprocess.Popen | None = None
        self._started_at: str | None = None

    def start(self) -> bool:
        with self._lock:
            if self._proc is not None and self._proc.poll() is None:
                return False
            self._log.parent.mkdir(parents=True, exist_ok=True)
            with self._log.open("w") as log:
                self._proc = subprocess.Popen(self._cmd, stdout=log, stderr=subprocess.STDOUT)
            self._started_at = datetime.now(UTC).isoformat(timespec="seconds").replace("+00:00", "Z")
            return True

    def status(self) -> dict:
        returncode = None if self._proc is None else self._proc.poll()
        tail = self._log.read_text(errors="replace").splitlines()[-TAIL_LINES:] if self._log.exists() else []
        return pull_status(self._started_at, returncode, tail)
```

```python
"""Data API: coverage and gaps per series, rollover calendar, background pull."""

from dataclasses import asdict
from datetime import UTC, date, datetime

from fastapi import APIRouter, HTTPException, Request

from fenrir.core.instruments import Instruments, front_month, load_instruments
from fenrir.core.sessions import trading_day
from fenrir.data.store import coverage

SERIES = ("ES", "NQ")

router = APIRouter(prefix="/api/data")


def front_months(instruments: Instruments, day: date) -> dict[str, str | None]:
    def one(series: str) -> str | None:
        try:
            return front_month(instruments, series, day)
        except ValueError:  # day outside the rollover calendar
            return None

    return {s: one(s) for s in SERIES}


@router.get("")
def overview(request: Request) -> dict:
    data_dir = request.app.state.settings.data_dir
    instruments = load_instruments()
    return {
        "series": [asdict(coverage(data_dir, s)) for s in SERIES],
        "rolls": [asdict(r) for r in instruments.rolls],
        "front": front_months(instruments, trading_day(datetime.now(UTC))),
        "pull": request.app.state.pull.status(),
    }


@router.post("/pull", status_code=202)
def pull(request: Request) -> dict:
    runner = request.app.state.pull
    if not runner.start():
        raise HTTPException(409, "A pull is already running.")
    return runner.status()
```

```ts
import { ApiError } from './api'

/** FastAPI errors arrive as `{"detail": ...}`; show the detail, not the raw JSON. */
export function errorText(e: unknown): string {
  if (!(e instanceof ApiError)) return String(e)
  try {
    const detail = (JSON.parse(e.body) as { detail?: unknown }).detail
    return typeof detail === 'string' ? detail : JSON.stringify(detail)
  } catch {
    return e.message
  }
}
```

import { Alert, AlertDescription } from '@/components/ui/alert'
import { Badge } from '@/components/ui/badge'
import { Button } from '@/components/ui/button'
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from '@/components/ui/table'
import { cn } from '@/lib/utils'
import { apiFetch } from '../api'
import { errorText } from '../errorText'

type Coverage = { series: string; first_day: string | null; last_day: string | null; days: number; gaps: [string, string][] }
type Roll = { series: string; start: string; contract: string }
type Pull = { state: 'idle' | 'running' | 'done' | 'error'; started_at: string | null; returncode: number | null; log_tail: string[] }
type Overview = { series: Coverage[]; rolls: Roll[]; front: Record<string, string | null>; pull: Pull }

function DataPage() {
  const qc = useQueryClient()
  const data = useQuery({
    queryKey: ['data'],
    queryFn: () => apiFetch<Overview>('/api/data'),
    refetchInterval: (q) => (q.state.data?.pull.state === 'running' ? 2000 : false),
  })
  const pull = useMutation({
    mutationFn: () => apiFetch<Pull>('/api/data/pull', { method: 'POST' }),
    onSettled: () => qc.invalidateQueries({ queryKey: ['data'] }),
  })
  if (!data.data) return <p className="text-muted-foreground">{data.error ? errorText(data.error) : 'Loading…'}</p>
  const { series, rolls, front, pull: status } = data.data
  return (
    <>
      <h1>Data</h1>
      <div className="grid gap-6">
        <Card role="region" aria-label="Coverage">
          <CardHeader>
            <CardTitle>Coverage (1-minute bars)</CardTitle>
          </CardHeader>
          <CardContent className="space-y-2">
            <Table>
              <TableHeader>
                <TableRow>
                  <TableHead scope="col">Series</TableHead>
                  <TableHead scope="col">First day</TableHead>
                  <TableHead scope="col">Last day</TableHead>
                  <TableHead scope="col">Trading days</TableHead>
                  <TableHead scope="col">Gaps</TableHead>
                </TableRow>
              </TableHeader>
              <TableBody>
                {series.map((c) => (
                  <TableRow key={c.series}>
                    <TableHead scope="row">{c.series}</TableHead>
                    <TableCell>{c.first_day ?? '—'}</TableCell>
                    <TableCell>{c.last_day ?? '—'}</TableCell>
                    <TableCell>{c.days}</TableCell>
                    <TableCell>
                      {c.gaps.length === 0 ? (
                        'none'
                      ) : (
                        <details>
                          <summary className="cursor-pointer text-primary">{c.gaps.length}</summary>
                          <ul className="mt-1 text-sm text-muted-foreground">
                            {c.gaps.map(([a, b]) => (
                              <li key={a}>{a === b ? a : `${a} → ${b}`}</li>
                            ))}
                          </ul>
                        </details>
                      )}
                    </TableCell>
                  </TableRow>
                ))}
              </TableBody>
            </Table>
            <p className="text-sm text-muted-foreground">MES and MNQ use the ES and NQ prices.</p>
          </CardContent>
        </Card>

        <Card role="region" aria-label="Pull">
          <CardHeader>
            <CardTitle>Pull from LSE</CardTitle>
          </CardHeader>
          <CardContent className="space-y-3">
            <Button type="button" onClick={() => pull.mutate()} disabled={status.state === 'running' || pull.isPending}>
              {status.state === 'running' ? 'Pulling…' : 'Pull'}
