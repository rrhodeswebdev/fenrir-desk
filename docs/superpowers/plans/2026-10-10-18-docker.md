# Docker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Anyone can `git clone`, `cp .env.example .env`, `docker compose up` and open `http://localhost:8000`: the built UI, the server, the CLI, Claude Code and `git` run in one container reachable from this machine only.

**Architecture:** Multi-stage `Dockerfile`: a Node stage builds `web/dist`; the Python runtime stage installs the package with `uv` into `/opt/venv`, copies the built UI to `/opt/fenrir/web-dist`, and installs Claude Code for a non-root `fenrir` user. The repo is bind-mounted at `/app` (the terminal's working directory). Inside the container the server must listen on `0.0.0.0` for Docker's port publishing to reach it, so `fenrir serve` binds all interfaces only when `FENRIR_BIND_ALL=1`, which only the image sets; `compose.yaml` publishes `127.0.0.1:8000:8000` so the host side stays loopback-only. Token, Host and Origin checks are unchanged.

**Tech Stack:** Docker, Docker Compose, `node:22-slim`, `python:3.12-slim`, `uv`, Claude Code native installer.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§11 running and installing, §7 security requirements)

**Index:** `docs/superpowers/plans/README.md` (contracts: "Plan 11 — server", "Plan 01 — settings")

## Global Constraints

- Run: `git clone <repo> && cd fenrir-desk`, `cp .env.example .env`, `docker compose up`; open `http://localhost:8000`.
- Dockerfile is multi-stage: Node builds the UI; the Python runtime stage (with `uv`) holds the server, CLI, built UI, Claude Code and `git`.
- `restart: unless-stopped`.
- Docker publishes `127.0.0.1:8000:8000`, never `8000:8000`.
- Named volume: Claude Code login (the user signs in once).
- NinjaTrader address: `host.docker.internal:<port>` when NinjaTrader runs on the same Windows host; the VM's IP for macOS + VM.
- Develop natively: `uv run fenrir serve` and `npm run dev`.
- `.env` is the single source of settings: it reaches the container through the repo bind mount only. Do **not** add `env_file:` or `environment:` with `FENRIR_*` settings to `compose.yaml` — `load_settings` lets `os.environ` override `.env`, so that would silently override edits made on the Settings page (plan 24). The image's only `FENRIR_*` variable is `FENRIR_BIND_ALL`, which is not a `Settings` field.
- **Deviation from spec §11 bind mounts (flag in PR):** the spec lists separate mounts for `strategies/`, `rules/`, `instruments.yaml`, `data/`, `.env`. This plan mounts the whole repo at `/app` instead (a superset of those), because §7 requires the terminal to start "in the repo directory" and Claude needs `.claude/skills/`, the `CLAUDE.md` files and `.git` there. If the user rejects this, replace `.:/app` with the five listed mounts and accept that the skill and git are unavailable in the terminal.

## Review Focus

1. **Port mapping widened to `8000:8000`** (a user "fixing" access from another device) exposes a shell to the LAN. Expect: a test fails. Test: `test_compose_ports_loopback_only` (Task 2).
2. **Server bound to 127.0.0.1 inside the container** — Docker's published port then gets connection resets, the classic "works natively, not in Docker" failure. Expect: `FENRIR_BIND_ALL=1` → `0.0.0.0`. Test: `test_bind_host` (Task 1) plus the `curl` check in Task 2.
3. **Claude Code login lost on every `docker compose up --build`** — the user must sign in once only. Expect: `CLAUDE_CONFIG_DIR` points into the named volume. Check: Task 2 Step 6 (rebuild and confirm still logged in).
4. **`git status` in the terminal fails with "dubious ownership"** because the bind-mounted repo's owner differs from the container user. Expect: works. Fix: `safe.directory /app`; check in Task 2 Step 5.
5. **`uv run ...` in the terminal tries to re-sync into the image's venv** (fails with permission errors or downloads dev deps), breaking the skill's ad-hoc data command. Expect: `uv run python -c "import fenrir"` works offline. Fix: `UV_NO_SYNC=1`; check in Task 2 Step 5.

```python
from fenrir.cli.serve import bind_host


def test_bind_host():
    assert bind_host({}) == "127.0.0.1"
    assert bind_host({"FENRIR_BIND_ALL": "0"}) == "127.0.0.1"
    assert bind_host({"FENRIR_BIND_ALL": "true"}) == "127.0.0.1"

def test_serve_bind_all_in_container(monkeypatch, tmp_path):
    calls = {}
    monkeypatch.setenv("FENRIR_BIND_ALL", "1")
    monkeypatch.setattr(serve_mod.uvicorn, "run", lambda a, **kw: calls.update(kw))
```

- [ ] **Step 3: Write minimal implementation**

In `src/fenrir/cli/serve.py` add `import os` and `from collections.abc import Mapping` to the imports, add the function above `serve`:

```python
def bind_host(env: Mapping[str, str]) -> str:
    # Only the Docker image sets FENRIR_BIND_ALL; compose publishes the port on 127.0.0.1 only.
    return "0.0.0.0" if env.get("FENRIR_BIND_ALL") == "1" else "127.0.0.1"
```

and replace the last line of `serve`:

```python
    uvicorn.run(app, host=bind_host(os.environ), port=port)
```

- [ ] **Step 2: Write the Dockerfile and ignore file**

`Dockerfile`:

```dockerfile
# syntax=docker/dockerfile:1

# --- UI build ---
FROM node:22-slim AS web
WORKDIR /web
COPY web/package.json web/package-lock.json ./
RUN npm ci
COPY web/ ./
RUN npm run build

# --- runtime ---
FROM python:3.12-slim
COPY --from=ghcr.io/astral-sh/uv:latest /uv /uvx /bin/
RUN apt-get update \
 && apt-get install -y --no-install-recommends bash ca-certificates curl git \
 && rm -rf /var/lib/apt/lists/*
RUN useradd --create-home --shell /bin/bash fenrir

# The package lives in /opt so the repo bind-mounted at /app cannot shadow it.
ENV UV_PROJECT_ENVIRONMENT=/opt/venv UV_COMPILE_BYTECODE=1 UV_LINK_MODE=copy
WORKDIR /opt/fenrir
COPY pyproject.toml uv.lock README.md ./
RUN uv sync --frozen --no-dev --no-install-project
COPY src ./src
RUN uv sync --frozen --no-dev --no-editable
COPY --from=web /web/dist /opt/fenrir/web-dist

USER fenrir
RUN curl -fsSL https://claude.ai/install.sh | bash \
 && mkdir -p /home/fenrir/.claude-config \
 && git config --global --add safe.directory /app
ENV PATH=/opt/venv/bin:/home/fenrir/.local/bin:$PATH \
    CLAUDE_CONFIG_DIR=/home/fenrir/.claude-config \
    UV_NO_SYNC=1 \
    SHELL=/bin/bash \
    FENRIR_BIND_ALL=1

WORKDIR /app
EXPOSE 8000
CMD ["fenrir", "serve", "--port", "8000", "--static-dir", "/opt/fenrir/web-dist"]
```

`.dockerignore`:

```
.git
.venv
.env
data
web/node_modules
web/dist
web/test-results
web/playwright-report
**/__pycache__
```
