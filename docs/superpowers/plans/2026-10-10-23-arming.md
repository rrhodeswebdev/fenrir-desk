# Arming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user, and only the user through the UI, arm a backtested strategy on a NinjaTrader account (one per account) and disarm it, with a confirmation showing the backtest summary before arming a live account.

**Architecture:** A pure `decide(...) -> Armed | Refusal` in `fenrir.live.arming` holds every arming rule (current file hash backtested against the account type and contract, mode matches the account, live needs confirmation). Thin FastAPI handlers in `server/routes/arming.py` and `server/routes/strategies.py` gather inputs (strategy file, reports, NinjaTrader accounts, SQLite) and forward to it. The Strategies page lists files, params and backtests and runs the arm flow: POST → on `409 needs_confirmation` show a shadcn `AlertDialog` with the summary → POST again with `confirm: true`.

**Tech Stack:** Python 3.12, FastAPI, sqlite3, pytest; React 19 + TypeScript, TanStack Query, Playwright. UI: Tailwind CSS v4 utility classes + shadcn/ui components (`@/components/ui/*`, set up in plan 12; add missing ones with `npx shadcn@latest add`); no custom CSS classes or inline styles except runtime-computed values.

**Spec:** `docs/superpowers/specs/2026-10-10-fenrir-desk-v1-design.md` (§7 "Arming is user-only", §8, §10 Strategies page)

**Index:** `docs/superpowers/plans/README.md` (cross-plan contracts: "Plans 21–24 — live API and storage", "Plans 09/10", "Plan 07", "Plan 11", "Plan 12")

## Global Constraints

- Functional core, imperative shell: `decide` is pure (no clock, no I/O); handlers only gather inputs, call it, and write the result.
- No CLI command arms or disarms a strategy. The arm endpoints sit behind `require_token`; the PTY never receives the token (plan 13).
- Arming requires a backtest whose `strategy_hash` equals the strategy file's current sha256, against the requested account type (`rules_account`) and contract. If the file changed since, the user must re-run the backtest.
- Arming a live (non-sim) account requires confirmation showing the backtest summary.
- One armed strategy per account: `armed.account` is the PRIMARY KEY. Plan 21's `insert_armed` replaces, so the arm endpoint checks `list_armed` first and refuses a second arm with `already_armed`, never a silent replace.
- Modes: `dry` (no orders sent; NinjaTrader not consulted), `sim` (needs an `is_sim` account), `live` (needs a non-sim account).
- API shapes exactly as in the index: `GET /api/arming` → `Armed[]`; `POST /api/arming/arm` → `200 Armed` | `409 {error, summary}`; `POST /api/arming/disarm`; `GET /api/strategies`.
- Query keys: `['strategies']`, `['arming']`, `['arming', 'accounts']`.
- Commits: Conventional Commits, scopes `live`, `server`, `web`.

## Review Focus

1. Strategy file edited by Claude after its backtest, then armed: refused with `hash_changed`, nothing armed. (Task 2: `test_edited_file_is_refused_with_hash_changed`.)
2. `strategy_path` pointing outside `strategies/` (e.g. `../evil.py`): 400, file never imported. (Task 2: `test_strategy_outside_strategies_dir_is_rejected`.)
3. Arming an account that already has an armed strategy: 409 `already_armed`, the existing row unchanged. (Task 2: `test_second_arm_on_same_account_is_refused_and_row_kept`.)
4. NinjaTrader unreachable while arming sim/live: 502 `nt_unavailable`, nothing armed; dry run still arms. (Task 2: `test_nt_unreachable_blocks_sim_but_not_dry`.)
5. A backtest exists for this file and account but a different contract (NQ vs MNQ): refused `no_backtest`, so NQ signals never trade an unbacktested contract. (Task 1: `test_report_for_other_contract_does_not_count`.)
6. Arming the evaluation phase on an account type with no evaluation (Lucid Direct): refused `no_evaluation_phase`, so the runner never builds rules for a phase that does not exist. (Task 1: `test_evaluation_phase_on_account_without_evaluation_is_refused`.)

```python
Mode = Literal["dry", "sim", "live"]
PhaseName = Literal["evaluation", "funded"]


@dataclass(frozen=True, slots=True)
class ArmRequest:
    account: str
    strategy_path: str
    rules_account: str
    contract: str
    mode: Mode
    phase: PhaseName
    confirm: bool


@dataclass(frozen=True, slots=True)
class Refusal:
    error: str
    summary: dict[str, Any] | None = None


def decide(req: ArmRequest, strategy_name: str, strategy_hash: str, reports: Sequence[Report],
           is_sim: bool | None, has_evaluation: bool, now: datetime) -> Armed | Refusal:
    """May this strategy file be armed on this account? `reports` newest first; `is_sim` None = unknown account."""
    if req.mode != "dry":
        if is_sim is None:
            return Refusal("unknown_account")
        if is_sim != (req.mode == "sim"):
            return Refusal("mode_mismatch")
    if req.phase == "evaluation" and not has_evaluation:
        return Refusal("no_evaluation_phase")
    same = [r for r in reports if r["strategy"] == strategy_name
            and r["account"] == req.rules_account and r["contract"] == req.contract]
    current = next((r for r in same if r["strategy_hash"] == strategy_hash), None)
    if current is None:
        return Refusal("hash_changed" if same else "no_backtest")
    if req.mode == "live" and not req.confirm:
        return Refusal("needs_confirmation", current["periods"]["tuning"])
    return Armed(req.account, req.strategy_path, strategy_hash, req.rules_account, req.contract,
                 req.mode, req.phase, now)
```

```python
# src/fenrir/server/routes/arming.py
"""Arm and disarm strategies on NinjaTrader accounts. UI-only: no CLI counterpart, and the PTY never has the token."""

from __future__ import annotations

import sqlite3
from contextlib import closing
from dataclasses import asdict
from datetime import UTC, datetime
from pathlib import Path
from typing import Any, Literal

import httpx
from fastapi import APIRouter, Depends, HTTPException, Request
from fastapi.responses import JSONResponse
from pydantic import BaseModel, ConfigDict

from fenrir.backtest.cache import list_reports
from fenrir.live.arming import ArmRequest, Refusal, decide, delete_armed, insert_armed, list_armed
from fenrir.live.journal import open_db
from fenrir.rules.loader import load_account
from fenrir.server.auth import require_token
from fenrir.strategy import load_strategy

router = APIRouter(prefix="/api/arming", dependencies=[Depends(require_token)])


class ArmBody(BaseModel):
    model_config = ConfigDict(extra="forbid")
    account: str
    strategy_path: str
    rules_account: str
    contract: str
    mode: Literal["dry", "sim", "live"]
    phase: Literal["evaluation", "funded"]
    confirm: bool = False


class DisarmBody(BaseModel):
    model_config = ConfigDict(extra="forbid")
    account: str


def _db(request: Request) -> sqlite3.Connection:
    return open_db(request.app.state.settings.data_dir / "fenrir.db")


def _refuse(error: str, status: int, summary: dict[str, Any] | None = None) -> JSONResponse:
    return JSONResponse({"error": error, "summary": summary}, status_code=status)


@router.get("")
def armed(request: Request) -> list[dict[str, Any]]:
    with closing(_db(request)) as conn:
        return [asdict(a) for a in list_armed(conn)]


@router.get("/accounts")
async def accounts(request: Request):
    try:
        return await request.app.state.addon.accounts()
    except httpx.HTTPError:
        return _refuse("nt_unavailable", 502)


@router.post("/arm")
async def arm(body: ArmBody, request: Request):
    settings = request.app.state.settings
    path = Path(body.strategy_path)
    if path.resolve().parent != settings.strategies_dir.resolve():
        raise HTTPException(400, "strategy_path must be a file directly in the strategies directory")
    try:
        strategy = load_strategy(path)
    except Exception as e:  # importing the user's file can raise anything
        raise HTTPException(400, f"cannot load strategy: {type(e).__name__}: {e}") from e
    try:
        rules = load_account(body.rules_account, settings.rules_dir)
    except ValueError as e:
        raise HTTPException(400, str(e)) from e
    is_sim = None
    if body.mode != "dry":
        try:
            nt_accounts = await request.app.state.addon.accounts()
        except httpx.HTTPError:
            return _refuse("nt_unavailable", 502)
        is_sim = next((a["is_sim"] for a in nt_accounts if a["id"] == body.account), None)
    result = decide(ArmRequest(**body.model_dump()), strategy.name, strategy.hash,
                    list_reports(settings), is_sim, rules.evaluation is not None, datetime.now(UTC))
    if isinstance(result, Refusal):
        return _refuse(result.error, 409, result.summary)
    with closing(_db(request)) as conn:
        if any(a.account == result.account for a in list_armed(conn)):  # insert_armed replaces; refuse instead
            return _refuse("already_armed", 409)
        insert_armed(conn, result)
    return asdict(result)


@router.post("/disarm")
def disarm(body: DisarmBody, request: Request) -> dict[str, bool]:
    with closing(_db(request)) as conn:
        existed = any(a.account == body.account for a in list_armed(conn))
```

```python
# src/fenrir/server/routes/strategies.py
"""Strategy files with their params and the backtests of their current contents."""

from __future__ import annotations

from collections.abc import Sequence
from pathlib import Path
from typing import Any

from fastapi import APIRouter, Depends, Request

from fenrir.backtest.cache import list_reports
from fenrir.backtest.report import Report
from fenrir.server.auth import require_token
from fenrir.strategy import file_hash, load_strategy

router = APIRouter(prefix="/api/strategies", dependencies=[Depends(require_token)])


def _brief(report: Report) -> dict[str, Any]:
    periods = {name: p and {k: v for k, v in p.items() if k != "sample_equity"}
               for name, p in report["periods"].items()}
    return {**report, "periods": periods}


def _entry(path: Path, current_hash: str, reports: Sequence[Report]) -> dict[str, Any]:
    base = {"name": path.stem, "path": str(path), "hash": current_hash, "market": None,
            "params": {}, "reports": [], "error": None}
    try:
        strategy = load_strategy(path)
    except Exception as e:  # a file Claude is still writing; show why instead of hiding it
        return base | {"error": f"{type(e).__name__}: {e}"}
    return base | {"market": strategy.market, "params": dict(strategy.params),
                   "reports": [_brief(r) for r in reports if r["strategy_hash"] == current_hash]}


@router.get("")
def strategies(request: Request) -> list[dict[str, Any]]:
    settings = request.app.state.settings
    reports = list_reports(settings)
    paths = sorted(p for p in settings.strategies_dir.glob("*.py") if not p.name.startswith("_"))
    return [_entry(p, file_hash(p), reports) for p in paths]
```

```tsx
/** One arm request. A live account's first request comes back as `{confirm: summary}`; the UI asks, then resends with confirm. */
async function armRequest(body: ArmBody): Promise<ArmResult> {
  try {
    await post<Armed>('/api/arming/arm', body)
    return { status: 'Armed.' }

    const refusal = JSON.parse(e.body) as { error: string; summary: PeriodResult | null }

    return { status: REFUSALS[refusal.error] ?? refusal.error }

  const accounts = useQuery({ queryKey: ['arming', 'accounts'], queryFn: () => apiFetch<NtAccount[]>('/api/arming/accounts') })
  return (
    <>
      <h1>Strategies</h1>
      <div className="space-y-6">
        <ArmedTable armed={armed.data ?? []} />
        {accounts.isError && <p className="text-sm text-muted-foreground">NinjaTrader accounts unavailable; dry run still works.</p>}
        {strategies.isError && <p role="alert" className="text-destructive">{String(strategies.error)}</p>}
        {strategies.data?.map((s) => <StrategyCard key={s.path} s={s} accounts={accounts.data ?? []} />)}
      </div>
    </>
  )
}
```
