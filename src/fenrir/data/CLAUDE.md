# src/fenrir/data/

Market data: pulling LSE history into Parquet, loading front-month bars, and (plan 04) building live 1-minute bars.

- Entry points: `store.py` (`SERIES` = ES, NQ, shared by `fenrir data` and `GET /api/data`; `load_bars`, `data_version`, `coverage`, `write_bars` for fixtures), `pull.py` (`pull_windows`, `todo`, `pull`), `lse.py` (LSE fetch; `stream_ticks`: live trades for front-month codes), `live.py` (`Tick`, `empty_builder`, `feed`, `close_due`: ticks → closed 1-minute bars; `stream_bars`: the LSE stream through the builder, closing each minute `LAG_GRACE` after it ends; `FeedStopped` when the SDK stops instead of reconnecting; permanent only for an empty `FENRIR_LSE_API_KEY`).
- Pure vs shell: `pull_windows`, `todo`, `find_gaps`, `with_contract` and the `live.py` builder are pure; `store.py` file I/O, `pull()`, `stream_ticks` and `stream_bars` (test seam `_bars_from(ticks, now, poll)`) are shell.
- Writes (DEC-1, #135): `data/` is terminal-writable in the image and the server's pull writes as root, so every store write goes through `_atomic_write(data_dir, path, write)`: it opens `data_dir` and each directory below it with `O_DIRECTORY|O_NOFOLLOW` (a dir-fd chain, creating missing ones with `mkdir(dir_fd=)`), creates a random-named temp file `O_EXCL|O_NOFOLLOW` (mode 0644) in the last one, then `os.replace`s it over `path` within that fd. A symlink on the way, even one swapped in mid-write, raises `ValueError` and writes nothing; a symlink at `path` is replaced, never followed. Without `dir_fd` (native Windows) `_atomic_write_checked` checks then writes and also refuses a symlinked `path`. `read_manifest` and `data_version` (both run in the root pull) share `_manifest_bytes`, which opens `bars/` through the same `O_NOFOLLOW` dir-fd walk (without creating it) and the manifest `O_NOFOLLOW|O_NONBLOCK` relative to it: a symlinked `bars/` or `manifest.json`, a non-regular file or one over 16 MB (`MAX_MANIFEST`) raises `ValueError`; a missing one reads as empty. `load_bars` and `coverage` (the Data page, root server) read each `*.parquet` through `fenrir.files.read_regular` (`MAX_PARQUET` = 256 MiB) and hand polars the bytes: a symlinked, FIFO, directory or oversized file is `ValueError` naming it (#140). `FENRIR_DATA_DIR` must be `data` under the server's cwd or a path whose ancestors are root-owned: only `data_dir` itself is opened `O_NOFOLLOW`, so a terminal-writable ancestor could be swapped for a link.
- `lse.py` is the ONLY module that knows about London Strategic Edge. Swapping providers = rewriting it alone.
- Prices are unadjusted front-month; front month comes from `fenrir.core.instruments.front_month`. Roll-window days (`fenrir.core.instruments.in_roll_window`) are never loaded or counted as gaps.
- `fenrir data summary` may list Good Fridays (e.g. 2024-03-29, 2025-04-18) as gaps: the CME calendar counts them as shortened sessions but LSE has no bars; NQ 2020-02-28 is genuinely missing (docs/data-gate.md).
- Not here: the files themselves (`data/bars/`), CLI (`cli/data.py`).
- Tests: `tests/data/`.
