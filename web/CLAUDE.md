# web/

The browser UI: Vite + React 19 + TypeScript (strict). Built to `web/dist/`, served by `fenrir serve`.

- Entry points: `src/main.tsx` (boot: `QueryClient` that does not retry a 401, `RouterProvider`), `src/router.tsx` (route tree; pages in `src/routes/`, shared components in `src/components/`), `src/api.ts` (`apiFetch`, `ApiError`, `wsUrl`: the only code that talks to the server), `src/errorText.ts` (`errorText(e)`: any error as readable text, 401 → "Session expired …"; `pageError(e)`: the same but null for a 401). "Session expired" shows only in the root shell's banner: pages show query errors with `pageError`, never `errorText` (the banner watches the query cache only, so a mutation's 401 still needs `errorText`). `src/rulesForm.ts` (pure helpers for the rules editor: `setIn`, `getIn`, `errorsAt`, `fieldErrors` for a 422's `{loc, msg}` list).
- Auth: the session is an HttpOnly cookie set by the server's `/launch` link. The page never sees it; same-origin requests carry it. No token in JS, headers or URLs.
- Style: function components + hooks; server state only in TanStack Query (keys `['<area>', ...args]`). Visual rules: root `PRODUCT.md` and `DESIGN.md`. Import from `src` as `@/...`.
- Theme and components: DESIGN.md's tokens, the `label`/`value`/`step` utilities and base `h1`/`h2`/`h3` live only in `src/index.css` (dark only; Tailwind's default colours, radii and shadows are removed there; `max-md:` is ≤ 760px). Fonts are `@fontsource` imports in `src/main.tsx`. The rail's mark is imported from `assets/brand/logo/` (Vite `server.fs.allow` admits only that directory outside `web/`, so a web build needs `assets/brand/` beside `web/`). shadcn/ui (Radix, New York; `components.json`) generates `src/components/ui/<name>.tsx`: add one with `cd web && npx shadcn@latest add <name>` in the task that first needs it, then make it meet DESIGN.md: replace `bg-black/*` (the scrim is `rgb(5 7 10 / 0.82)`) and `text-white` (both compile to nothing here), drop `rounded-*` including `rounded-full`, filled backgrounds and outward shadows, and drop `outline-none`/`outline-hidden` together with `ring-*` so the base Ember focus outline shows. `Button` variants are `outline` (default), `destructive` (red edge), `caution` (ember edge); sizes `default`, `sm`, `icon`. `cn()` is `@/lib/utils`. No hand-written CSS classes outside `index.css`.
- Dev: `uv run fenrir serve --dev` + `npm --prefix web run dev` (port 5173, proxies `/api`, `/ws` and `/launch` to `127.0.0.1:8000`); open the `:5173` launch link the server prints.
- Checks: `npm --prefix web run typecheck`; unit tests `npm --prefix web test -- --run` (Vitest, `src/**/*.test.{ts,tsx}`, node env: render with `react-dom/server`); `npm --prefix web run build`. Browser smoke: `npm --prefix web run e2e` (builds, then Playwright; once: `npx --prefix web playwright install chromium`). `e2e/global-setup.ts` starts `uv run fenrir serve --port 8799` (`FENRIR_E2E_PORT` overrides) from the repo root with data, private, rules and strategies dirs in a temp dir an empty `FENRIR_ENV_FILE` (the repo `.env` is never read) and dummy secrets, opens the launch link it prints, saves the cookie for the tests, and stops the server after. e2e specs never `POST /api/data/pull`.
- TypeScript 7 (native `tsc`). typescript-eslint does not support it: if ESLint is ever added, pin `typescript@~6.0.3`.
- Not here: business logic. Rules, backtests and live trading live in the Python package `src/fenrir/`.
