# web/src/backtests/

The parts of the Backtests page (`../routes/backtests.tsx`) that talk to the backtests API (`docs/contracts.md` "Plan 14 — backtest jobs API").

- Entry points: `RunForm.tsx` (`RunForm`: ticks strategies × accounts × contracts from `GET /api/backtests/options` (query `['backtests', 'options']`) and posts them to `POST /api/backtests/jobs`, then shows the new job id; no contract ticked sends `contracts: null`, every contract of each strategy's market; a 4xx shows via `errorText`). Pure helpers `toggle`, `jobBody`, `canRun`, `postJob` and the stateless `RunFormView` are exported for tests.
- `Report.tsx` (`Report`/`Period` types for `GET /api/backtests/results/{key}`; `ReportView`: run facts incl. `dll_on`, tuning and hold-out side by side with gross and net per attempt and the overlap note, params, then per period the days-to-pass histogram (HTML bars, text alternative in `aria-label`) and up to 6 `lightweight-charts` equity samples, each captioned in words; the canvas is `aria-hidden`). Pure helpers: `charts.ts` (`bins`, `histogramText`, `equitySeries`, `equityCaption`, `outcomeColor`, `chartOptions`: colours read from the `--chart-*`/`--rule` tokens at mount, dark only) and `format.ts` (`pct`, `num`, `money`, `paramText`).
- Not here: the page shell and routes (`../routes/backtests.tsx`, `../routes/backtest-report.tsx`), the job list and comparison (later tasks), grid expansion and validation (the server).
- Tests: `RunForm.test.tsx` (Vitest, node env, `renderToStaticMarkup`; `fetch` stubbed for the POST body); `charts.test.ts`, `format.test.ts`; the report page render is `../routes/backtest-report.test.tsx` (charts only draw in an effect, so a static render needs no mock).
