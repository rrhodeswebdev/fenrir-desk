# web/src/routes/

One file per UI page. Each exports `<page>Route` built with `createRoute({ getParentRoute: () => rootRoute, path, component })`, importing `rootRoute` from `./root`.

- Entry points: `root.tsx` (`rootRoute`: the index rail shell, the not-found page, and the "Session expired" line shown while any query's last error is a 401); `../router.tsx` assembles the tree, so add a new route there. A later task replaces a stub's `component` and nothing else in `router.tsx`.
- Pages: `/` workbench (xterm.js over `WS /ws/terminal`: pure `inputFrame`/`resizeFrame`/`closeLine`, theme read from the CSS tokens at mount, fit add-on + `ResizeObserver` sending resize frames, a disconnect line on close, no reconnect; the 'Latest backtest' region beside it), `/rules` (rule files with staleness; `?account=<id>` opens that file in the field-by-field editor beside the list: draft state only through `setIn`, Save → `PUT`, 422 errors under their input by `loc` plus a summary; every schema field, including `funded.scaling` tiers with Add/Remove), `/data`, `/backtests`, `/backtests/$key` (`backtest-report.tsx`: the report for that cache key, query `['backtests', 'results', key]`, no retry on a 404, rendered by `@/backtests/Report`), `/strategies`, `/live`, `/settings` (two forms like the rules editor, each sending only edited keys: the six secrets-file settings, secrets shown as their masks; per-account `eval_price` and `dll_on`; when `repo_env_secrets`, an Ember warning with the import button). Each renders `<Page title strip>` from `@/components/page`.
- Data: `useQuery({ queryKey: ['<area>', ...], queryFn: () => apiFetch(...) })` from `@/api`; mutate with `useMutation` and invalidate the area's keys. No `fetch` outside `../api.ts`. Show errors with `pageError(e)` (null for a 401: the shell's banner reports it).
- Not here: shared components (`../components/`).
- Tests: `root.test.tsx` renders each path with `renderToString` (no DOM); a page with data gets its own `<page>.test.tsx` that seeds the query cache with `setQueryData`; a page's pure helpers are exported from its file and tested in `<page>.test.ts` (e.g. `data.test.ts`: roll rows, poll interval); browser flows in `web/e2e/` (#38).
